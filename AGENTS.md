# «Белая Сова · Спуск» — руководство для разработчика и ИИ-ассистента

Этот файл — первое, что нужно прочитать перед любой правкой. Его автоматически читают Codex, Claude Code и другие ИИ-агенты; человеку он тоже подходит.

## Что это
Мобильная 3D-игра-«раннер» про горнолыжный склон в Шахтерске. Бренд EMCO. Герои: **Мишаня** (медведь, лыжи, сносит сугробы) и **Сова** (сноуборд, дольше парит в прыжке). Игра учит **10 правилам FIS** (поведение на склоне). Работает как **Telegram Mini App** (бот @belaya_sovabot, ссылка https://t.me/belaya_sovabot/play) и как обычный сайт https://magliot.github.io/belaya-sova/.

## Структура репозитория
```
docs/                 ← САЙТ ИГРЫ (GitHub Pages публикует эту папку как есть)
  index.html          ← вся игра: HTML + CSS + JS-модуль (~1820 строк, очень длинные строки — читать кусками)
  version.txt         ← версия для автообновления в Telegram (см. «Выпуск версии»)
  models/*.js         ← 3D-модели GLB, упакованные в base64: window.__GLB[key]="…"
    mishka.js (bear), sova.js (owl), npc.js (skier,kid,sitter,ratrak,tree),
    npc2.js (sboy,sman,sinstr,chair,tower), props.js (mandarin,cocoa,helmet), trees.js (pine,fir,ramp)
  models/sounds.js    ← старые реплики героев в base64: window.__SND["owl_start"] и т.п.
  audio/*.mp3         ← музыка (music_menu, music_run) и новые реплики bear_/owl_ + record|polite|warn|miss|feather|stage
  audio/sfx/land_*.mp3← хруст снега (Kenney, CC0) — единственный звук-файл, остальные эффекты синтезируются
  ui/                 ← аватары героев, фон меню menu_bg.jpg
  vendor/three/       ← three.js 0.160 (свой экземпляр, без CDN — работает в РФ без VPN)
  fonts/              ← шрифт Rubik (woff2)
server/apps-script/Code.gs ← РАБОЧИЙ сервер рекордов (Google Apps Script + Google Таблица)
tgcloud/, tgcloud.jsonc, package.json ← запасной сервер на Telegram Serverless (не запущен: лист ожидания)
tools/                ← скрипты подготовки ассетов (сжатие GLB, обрезка, упаковка, локальный сервер)
handoff/              ← отчёт о работе, план, инструкции по сервисам
```
Сборки нет: правишь `docs/index.html` → проверяешь локально → `git push` → через 1–2 минуты игра обновлена.

## Как запустить локально
```
node tools/serve.cjs docs 8766      # затем открыть http://localhost:8766/
```
Любой статический сервер подойдёт (`npx serve docs`, `python -m http.server` из docs). Открывать `index.html` двойным кликом нельзя — модули и fetch не работают с file://.
Для отладки на телефоне-размере — DevTools, режим 375×812.

| SAVE / MISSIONS | `save` (localStorage + Telegram CloudStorage), `SAVE_KEYS`, задания `MPOOL`, `HEROES` (параметры героев) |
| AUDIO | 3 шины громкости (музыка/звуки/голоса), синтез `tone()/noise()`, `SFX.*`, `voice()`, музыка `music()`, мотор ратрака `catAudio()`, гул лавины `rumble()`, клики меню `uiPop()` |
| ZONES / ЭТАПЫ | освещение (день, вечер, метель, ночь, праздник) и 8 этапов `STAGES` по 2500 м с весами препятствий `mix` |
| GAME STATE | `newGame()`, `G` — всё состояние заезда, `G.p` — герой |
| INPUT | палец: влево-вправо — руль; **держишь палец — разгон**, тянешь вниз — тормоз, отпустил — медленнее; в прыжке **свайп — трюк** (8 направлений), тап — случайный |

## Выпуск версии (ОБЯЗАТЕЛЬНО при каждом push)
Telegram держит старую копию страницы. В начале `index.html` есть `VER='…'`, игра сверяет его с `docs/version.txt` и один раз перезагружается, если они разные. Поэтому при каждом выпуске:
1. поменять `VER='…'` в `docs/index.html` **и** содержимое `docs/version.txt` на одно и то же новое значение (формат `ГГГГ-ММ-ДДx`);
2. `git add -A && git commit -m "…" && git push`.

## Сервер рекордов
Рабочий: **Google Apps Script** (`server/apps-script/Code.gs`) при Google Таблице «Белая Сова — рекорды» (листы «Игроки», «Журнал»). Адрес `/exec` вписан в игру как `API_URL`.
- Игра шлёт POST `text/plain` с `{action:'submit'|'leaderboard', initData, …}`; сервер проверяет подпись Telegram (`verifyInitData`, HMAC от BOT_TOKEN) и правдоподобие очков (`dist ≤ dur·45+20`, `bonus ≤ dist·45+3000`).
- Бот отвечает на /start /top /alltime /channel через **опрос** (`pollUpdates`, триггер раз в минуту) — вебхук на Apps Script не работает (302).
- Токен бота хранится **только** в «Свойствах скрипта» (`BOT_TOKEN`). Никогда не печатать его в логи: все ошибки логировать через `redact()`.
- После правки Code.gs: вставить код в редактор Apps Script (Ctrl+A → Delete → Ctrl+V, иначе код задублируется), сохранить, «Развертывание → Управление → ✏️ → Новая версия». Адрес не меняется.
Подробно — `handoff/СЕРВЕР_И_TELEGRAM.md`.

## Ассеты: модели, звук, картинки
- 3D-модели делались в **Tripo** (text-to-3D, ~45 кредитов за модель), риг героев — Mixamo-подобный скелет из Tripo.
- Перед упаковкой GLB сжимать: `node tools/shrink.mjs in.glb out.glb 0.25 512` (упрощение сетки + текстуры 512 JPEG; ресайз через PowerShell System.Drawing — на Windows; на другой ОС замените на sharp/ImageMagick).
- Упаковать: `node tools/pack-models.mjs docs/models/trees.js pine=pine_s.glb fir=fir_s.glb ramp=ramp_s.glb`.
- `tools/clip.mjs` — вырезать часть модели (так из кресла убрали опору), `profile.mjs`/`probe2.mjs`/`boardaxis.mjs` — замеры габаритов и оси доски.
- Музыка — Suno (через Syntx), голоса героев — ElevenLabs (через Syntx), картинки — GPT Image (через Syntx). Исходники лежат в архиве переноса, папка `исходники/`.
- Звуковые эффекты синтезируются кодом (`SFX`), файл только у хруста снега. Пользователю НЕ понравились наборы Kenney — не возвращать.

## Правила и предпочтения владельца (важно)
- Общение и тексты в игре — на русском.
- Звуки: мягкие, «вкусные», негромкие; частые звуки (ворота, обгоны) — тихие или редкие. Хруст снега не громче остального.
- Всплывающие плашки — компактные, полупрозрачные, в стиле меню (дерево + крем + снежные шапки).
- Меню: герой целиком на снегу без снаряжения, снаряжение воткнуто рядом; оба героя одного размера.
- Соперник — второй герой (у Мишани — Сова, у Совы — Мишаня), едет «как профи»: плавно, проходит все ворота, трюки на трамплинах и изредка, без подписи над головой.
- Игра должна требовать управления: нельзя долго ехать, не трогая экран.
- Каждое изменение — проверить в браузере в размере телефона, потом выпускать.

## Безопасность
- Токены и пароли не хранить в репозитории (он публичный — GitHub Pages). `API_URL` публичен намеренно.
- Не выводить значения «Свойств скрипта» в логи и ответы.
- Репозиторий публичный: не класть сюда личные данные, ID таблиц и т.п.

## Отладка
- Временный `docs/test.html` = копия index.html + в конце `window.__dbg={get G(){return G},update,render,…}` — даёт доступ к внутренностям из консоли (модуль сам ничего не экспортирует). **Не коммитить**, удалять перед выпуском.
- Если вкладка браузера скрыта, requestAnimationFrame стоит и игра уходит на паузу — гонять кадры вручную: `__dbg.update(1/60); __dbg.render(1/60)`.
- Быстрые «прогоны ботом»: цикл `update(1/60)` тысячи раз с простым автопилотом — так проверялись соперник (ворота/касания) и баланс лавины.
