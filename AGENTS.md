# «Белая Сова · Спуск»

## Действующая игра

Разрабатываем только Unity 6.3 LTS + URP. Исходники находятся в `unity/OwlSlope`, сцена полного спуска — `Assets/Mountain.unity`. Дальнейшие изменения меню, заезда, погоды, звука и графики делаем для этой игры. Исходную Three.js-версию используем как архив поведения, материалов и компоновки. [Как открыть архив](handoff/АРХИВ_THREE.md).

Обычная кнопка Telegram и корень GitHub Pages запускают `docs/unity/`. Для проверок есть `docs/unity-test/` с отдельным профилем. Оба адреса используют один WebAssembly и один экран выбора героя. Старый путь `/unity-slope/` переводит в тест полной игры. Точка входа Pages — `docs/index.html`, передача параметров Telegram — `docs/motion-entry.js`.

## Работа над игрой

- Физика и события находятся в `Assets/MountainRace*.cs`, расстановка и отображение трассы — в `Assets/RaceWorld*.cs`. Ресурсы трассы лежат в `Assets/Resources/Race/`. Осмотр и Play Mode используют те же объекты, что и обычный заезд.
- Меню, HUD, Web Audio и интеграция с Telegram находятся в `Assets/WebGLTemplates/MountainRace`. Правьте исходники шаблона. Обе опубликованные страницы формирует `tools/build-unity-race.ps1`, он привязывает адреса CSS и JS к содержимому и разделяет конфигурации рейтинга.
- Общайтесь и пишите игровой текст по-русски. Заезд одиночный. Героя, людей на склоне, снаряжение и контакт со снегом оценивайте в движении в портретном окне. События не должны загораживать дорогу. Звуки частых действий делайте тихими. Реплику о награде запускайте при её получении.
- Записывайте изменения, seed, контрольные метры, ссылки и фактически проверенные устройства в [handoff/STATUS.md](handoff/STATUS.md). Последние решения по трассам и режимам собраны в [геймдизайне](Belaya_Sova_VSCode/GAME_DESIGN.md).

## Сборка, проверка и выпуск

Для независимых проверок прогрессии используйте `tools/build-unity-race.ps1 -Preview` и каталог `docs/progression-test/`. Адрес приёмки есть в `handoff/STATUS.md`. У теста отдельный профиль и анонимная таблица. Основная кнопка Telegram открывает основной зачётный спуск в `docs/unity/`. Параметр `unitytest_progress21` открывает тестовую версию.

Каждое готовое игровое исправление сразу после проверки публикуйте на обычной кнопке бота для теста с телефона. После проверки опубликованного заезда сообщайте владельцу ссылку Telegram, версию и, если важен конкретный участок, seed и метры.

Из корня выполнить `powershell -ExecutionPolicy Bypass -File tools/build-unity-race.ps1 -Verify`, затем `powershell -ExecutionPolicy Bypass -File tools/build-unity-race.ps1`. Запустить `node tools/serve.cjs docs 8784`. В браузере проверить [обычный вход](http://127.0.0.1:8784/?seed=1911) за обоих героев. Команды браузерных проверок приведены в [инструкции Unity](unity/OwlSlope/README.md). Для замеров на устройстве откройте настройки → «Замеры» после заезда.

При выпуске синхронизируйте `docs/version.txt`, версию входа в HTML и `docs/motion-entry.js`. GitHub Pages публикует папку `docs` ветки `main`. После публикации сверяйте контрольные суммы файлов плеера и запуск обычной кнопкой. [Основной вход в Telegram](https://t.me/belaya_sovabot/play).

Сервер рейтинга находится в `server/apps-script/Code.gs`. Боевой endpoint задан в `docs/unity/release.js`. Тестовые заезды проходят на отдельном профиле. BOT_TOKEN хранится в свойствах Apps Script. [Обслуживание сервера](handoff/СЕРВЕР_И_TELEGRAM.md).
