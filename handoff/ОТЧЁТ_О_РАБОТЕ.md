# Отчёт о разработке «Белая Сова · Спуск» (до 17.11.2026)

Игру делали в диалоге владельца с ИИ-ассистентом (Claude Code в приложении Claude для Windows). Владелец формулировал задачи голосом/текстом и проверял результат на телефоне в Telegram; ассистент писал код, проверял его в встроенном браузере (размер экрана телефона, скриншоты, прогоны ботом) и выкладывал через `git push`.

## Как была устроена работа
1. **Задача** от владельца (часто списком замечаний после игры на телефоне).
2. **Правка** `docs/index.html` (вся игра в одном файле) и при необходимости моделей/звуков.
3. **Проверка**: локальный сервер `tools/serve.cjs` на порту 8766, временная `docs/test.html` с доступом к внутренностям (`window.__dbg`), скриншоты в размере 375×812, автоматические прогоны (тысячи кадров `update(1/60)` с простым автопилотом) — так считали пропуски ворот, касания, время до столкновения без руления, баланс лавины.
4. **Выпуск**: смена `VER` + `docs/version.txt` → commit → push → GitHub Pages → Telegram подтягивает новую версию сам.
5. Владелец проверяет на телефоне и присылает следующие замечания.

Генерация ассетов шла через сервисы, в которые владелец входил сам (ассистент не вводил пароли и токены):
- **Tripo** (tripo3d.ai) — 3D-модели text-to-3D, ~45 кредитов за модель; работали через Chrome владельца.
- **Syntx** — агрегатор: Suno (музыка), ElevenLabs (голоса), GPT Image (картинки меню и обложка).
- **Kenney** — бесплатные CC0-звуки (в итоге оставлен только хруст снега).

## Хронология (что сделано)

### Этап 1. Основа (артефакт claude.ai)
Игра начиналась как артефакт на claude.ai (https://claude.ai/artifact/B8RA5TvsnQfS82VjfGhyQ4 — **устарел**, не использовать). Там появились: склон, ворота, трамплины и трюки, мандаринки, каски-жизни, задания, коллекция букв EMCO/СОВА/ШАХТЕРСК, золотые перья, йети, 8 этапов со сменой погоды, 10 правил FIS как коллекция.

### Этап 2. 3D-модели и визуал
- Модели из Tripo: Мишаня, Сова (со скелетом), лыжник, ребёнок, сидящий, ратрак, ёлки (tree/pine/fir), трамплин, мандаринка, какао, каска, сноубордисты (мальчик, мужчина, инструктор), кресло подъёмника с людьми, опора подъёмника. Каждую сжимали `shrink.mjs` и упаковывали в base64-JS.
- Меню в стиле референса: деревянная доска, кремовая панель, снежные шапки, лента с логотипом, аватары героев, шрифт Rubik, нарисованный фон (GPT Image), 3D-герой поверх фона.
- Всплывающие плашки в стиле меню, компактные и полупрозрачные.
- Спидометр, три ползунка громкости (музыка/звуки/голоса).

### Этап 3. Живой склон
- Сноубордисты едут «змейкой», уроки сноуборда (дети полукругом у инструктора), инструктор с 1–3 детьми колонной, подъёмник с креслами.
- NPC объезжают препятствия и друг друга, прыгают с трамплинов, сидящие ёрзают.
- Настоящие 3D-бугры (поля могулов), по которым герой подпрыгивает (исправлен баг «улёт в небо»).
- Анимации героев: падение по фазам (кувырок → лежит → встаёт) при спасении каской, палки прижаты в прыжке.

### Этап 4. Telegram
- Перенос на **GitHub Pages** (`docs/`), т.к. ссылка на артефакт требовала VPN и вход в Claude.
- Бот **@belaya_sovabot**, мини-приложение `play`: полноэкранный режим, кнопка «Назад», вибрация, облачные сохранения, отдельные сохранения для каждого Telegram-аккаунта, «Поделиться» в чат.
- **Сервер рекордов** на Google Apps Script: проверка подписи Telegram, рейтинг недели и всех времён, посты в канал, команды бота через опрос раз в минуту. (Telegram Serverless попробовали — там лист ожидания; код сохранён в `tgcloud/`.)
- Автообновление: игра сама перезагружается, если Telegram показал старую копию (`version.txt`).

### Этап 5. Звук
- Музыка меню и трассы (Suno), 12 новых реплик героев (ElevenLabs).
- Пробовали наборы Kenney — владельцу не понравились («режут слух»), вернули синтез; из Kenney остался хруст снега (сделан тише).
- Мягкий «поп» на всех кнопках меню; тихий «динь» на воротах; мотор ратрака громче с приближением + гудок; гул лавины.

### Этап 6. Танцы-награды
5 танцев в меню (покачивание сразу; флосс — 3 пера; прыжки — 20 подарков; дэб — 5000 очков; танец чемпиона — все 10 FIS), можно отправить в чат. Подъём лап в «прыжках» и «флоссе» исправлен 17.11 (см. этап 8).

### Этап 7. Геймплей (16.11)
- Ворота — сериями-слаломом 4–7 штук, шаг под скорость.
- Камни прямо на пути — без руления не проехать; больше людей, мандаринок, трамплинов, касок.
- **Скорость**: держишь палец — разгон (+25%, бонус-очки), тянешь вниз — тормоз, отпустил — медленнее.
- **Трюки свайпами** в прыжке: вверх (сальто назад / мисти-флип), вниз (грэб / сальто вперёд), влево (бочка / корк 720), вправо (вертушка / вертолёт 720); короткий и длинный свайп.
- **Соперник** — второй герой, едет весь заезд, обгоны в обе стороны, дразнится облачком («Догони меня!», «Сейчас догоню!») с коротким звуком; едет «как профи»: плавные дуги, проходит все ворота, объезжает или перепрыгивает препятствия.
- **Лавина** догоняет сзади 20 секунд — нужно держать разгон.
- **Испытания этапа**: мандаринки, ворота подряд, без касаний, трюки, вежливые обгоны.
- Ночной этап по-настоящему тёмный — видно только фонарик на шлеме.

### Этап 8. Исправление танцев (17.11)
- Во «флоссе» увеличен размах лап и добавлено движение плеч.
- В «прыжках» участвуют плечи, угол рук уменьшен, чтобы лапы не уходили за голову; цикл отрыва и приземления сделан плавным.

## Известные проблемы и ограничения
- Реплики соперника — только текстом + короткий звук; голосом не записаны (нужен тот же голос, что у героев, в Syntx/ElevenLabs).
- Бот отвечает с задержкой до минуты (опрос Apps Script). Для мгновенных ответов нужна прокси (например, Cloudflare Worker) или Telegram Serverless.
- `index.html` — один большой файл; при росте проекта стоит разнести на модули.
- Инструмент `shrink.mjs` ресайзит текстуры через PowerShell System.Drawing (только Windows).

## Уроки, которые стоит помнить
- Telegram кэширует страницу — без смены `VER`/`version.txt` игрок не увидит обновление.
- Вебхук бота на Apps Script не работает (Apps Script отвечает 302) — только опрос.
- Ошибки UrlFetchApp содержат URL с токеном бота — логировать только через `redact()`. Токен однажды утёк в журнал и в диагностику — его перевыпускали.
- При вставке кода в редактор Apps Script — сначала Ctrl+A, Delete, иначе код удваивается.
- Скрытая вкладка браузера останавливает анимацию — для тестов гонять кадры вручную.
- Перспектива: объект впереди кажется меньше — соперника слегка увеличиваем (до +35%), чтобы он «на глаз» был одного роста с игроком.
