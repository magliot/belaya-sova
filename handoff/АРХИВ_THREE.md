# Архив игры перед переносом в Unity

В теге `archive/three-local-20261120` находится полный снимок рабочего дерева Git на `0d90beb`, включая игровую папку `docs`, модели и исходники Blender, сервер, геймдизайн, инструкции и проверенный Unity-слалом. На момент снимка в `local/training-slope` рабочее дерево было чистым. Отдельный тег `archive/three-live-20261120` указывает на `7414fc5`, который обслуживал Telegram. Ветка разработки полной игры называется `migration/unity-web`.

Рядом с репозиторием лежит папка `archive-three-20261120`. В ней `three-local.zip` для запуска без Git, самодостаточный `belaya-sova.bundle` с историей обоих тегов, а также `local-checks-and-blender-backups.zip` с локальными проверочными материалами и файлами `.blend1`. SHA-256 каждого архива записан в `SHA256SUMS.txt`.

## Запустить старую игру рядом с новой

```powershell
git worktree add --detach ../sova-three archive/three-local-20261120
cd ../sova-three
node tools/serve.cjs docs 8783
```

Открыть [локальный браузерный заезд](http://127.0.0.1:8783/). Для воспроизведения именно выпущенной версии использовать `archive/three-live-20261120`. Распакованный ZIP запускается той же командой из папки с `AGENTS.md`.

В пустой папке историю можно восстановить без GitHub.

```powershell
git init sova-restored
cd sova-restored
git fetch ../archive-three-20261120/belaya-sova.bundle "refs/tags/archive/*:refs/tags/archive/*"
git switch -c restored-three archive/three-local-20261120
```

## Вернуть боевой вход

С выпуска 2026-11-20h кнопка бота ведёт через корень сайта в `/unity/`. Для испытаний используется `docs/unity-test/` и параметр `startapp=unitytest`. Оба адреса используют один плеер Unity. Для запуска старой игры используйте архивный тег.

Если в будущем основной вход переключён отдельным коммитом, откатить этот коммит через `git revert <коммит-переключения>` в обычной ветке исправления от актуальной `main`. Если требуется выпуск старой игровой папки целиком, восстановить её командой `git restore --source=archive/three-live-20261120 -- docs` в той же отдельной ветке. В обоих случаях задать новый идентификатор кэша в `docs/index.html` и `docs/version.txt`, проверить кнопку «Поехали!» за обоих героев и опубликовать обычным fast-forward или PR. Перед восстановлением всей папки сохранить последующие принятые изменения. Пользовательские данные Three.js остаются в исходных ключах браузера и Telegram.
