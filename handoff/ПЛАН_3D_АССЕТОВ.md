## Подготовка для игры

Оптимизированные GLB упакованы в `docs/models/winter.js`; исходные крупные файлы не публикуются. Текстуры до 512 пикселей, прозрачность сохраняется. Нормали распакованы из Meshopt/quantization; размеры и точка опоры нормализованы загрузчиком. Коллизии и параметры заезда не изменены.

Собака получила простой локальный скелет и цикл `winter_run`, снеговик и йети — локальные кости рук. Это подготовлено кодом без дополнительных списаний Tripo. Скелеты копий независимы. При недоступных моделях остаются процедурные объекты.

Восстановить GLB из репозитория:

```bash
npm ci --prefix tools
node tools/unpack-models.mjs docs/models/winter.js assets/tripo/optimized
```

Повторить сжатие и локальный риг:

```bash
node tools/shrink.mjs input.glb small.glb 0.25 512
node tools/rig-winter.mjs dog small.glb dog_rig.glb
```

Проверка в браузере 375×812 добавлена в `tools/check-assets.cjs` и GitHub Actions: загрузка восьми GLB, лимиты геометрии, независимость собак, движение лап, жесты рук, процедурный резерв и PNG каждого объекта. [CI 44011357647](https://github.com/magliot/belaya-sova/actions/runs/44011357647) прошёл успешно: ошибок JavaScript нет, все восемь объектов укладываются в лимиты. Движение лап собаки — 0.198 ед. при неподвижной голове; скелеты экземпляров независимы. Игровые проверки танцев, лавины, слалома и езды без руления также прошли. Кадры всех моделей и игры просмотрены. Версия 2026-11-17c, PR #3.
