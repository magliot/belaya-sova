# Проверка движений в игре

Рабочая точка продолжения: 17 ноября 2026.

Открыть `docs/animation-phone.html` через HTTP — игра в рамке 375×812. `docs/animation-test.html` — тот же тест на весь экран. Кнопки: Мишаня, Сова, стойка, влево, вправо, прыжок, посадка, играть.

- Подключены отдельные запечённые движения обоих героев, включая сноубордическую стойку Совы.
- У Мишани лыжи закантовываются вместе с ботинками; положение ног пересчитывается IK.
- Из ключей Hips и независимого снаряжения вычтен вертикальный полёт: высоту задаёт только игровая физика.
- Переходы поз сглаживаются; рукоятки после сглаживания закрепляются в пространстве кистей. Длина палок постоянна.
- Полёт использует airT/airMax игрока и соперника, посадка запускается при фактическом контакте.
- Меню, танцы, падения используют прежнюю модель и прежние движения.
- Тест отключает Telegram и отправку результатов; сохраняет прогресс под отдельным ключом.
- Опубликованный `docs/index.html` не изменён. Проба предназначена для оценки перед переносом в основную игру.

Проверки: `node tools/check-motion-integration.mjs` проверяет реальные GLB в Three.js 160 при 30/60 FPS: движения и переходы, контакт стоп с креплениями (отклонение до 0.0067 единицы модели), хват палок, отсутствие второго подъёма, неизменный масштаб костей, возврат в меню и падение. Отчёт: `runtime-check.json`.

Пересборка: `blender -b -t 4 --python tools/build-hero-pilot.py -- art/animation-pilot --no-render`, затем `node tools/build-animation-test.mjs`. Для Совы добавить `owl` и путь `art/owl-animation-pilot`.

Браузерная проверка: ожидает завершения. Локальный Chromium не запустился из-за ограничения системных сокетов; тест проверяется отдельным доступным браузером.

Дальше: оценить в движении на игровой камере; дорабатывать складки/крылья по наблюдаемым дефектам. Захваты снаряжения в трюках и новые танцы ещё не сделаны. Старое видео `art/animation-pilot/mishanya-ski-study.mp4` показывает предыдущую студийную пробу, а не текущую интеграцию.
